# TAITE（タイテ）

DJ Set Timer & Timetable — 自分の出番まで・セット残り時間をスマホで把握する。

DJイベントのタイムテーブルをリンクで共有し、各自のスマホで現在時刻・セットの残り時間を表示するPWA。サーバー・DB不要（タイムテーブルはURLの `#` 以降に圧縮して埋め込み）。

## 開発
```bash
npm install
npm run dev      # http://localhost:5173（同一Wi-Fiのスマホからも --host で確認可）
npm run build    # dist/ に出力
```

デバッグ: `?now=2026-11-21T21:55` を付けると現在時刻をずらして表示確認できる。

## 機能
- 表示言語: 英語。デザインは「DJ機材風の落ち着いた計器」（チャコールの地、状態で色が変わる数字とランプ、レベルメーター）。書体は Barlow（DIN系、数字は等幅）。操作はアイコン、表示のラベルは短い文字
- 画面: スマホ縦・横、折りたたみの外側（細い画面）、内側・タブレット（タイマーとタイムテーブルを左右に並べる）に対応
- 作成画面: iPhone の設定アプリのような構成（Event / Sets / Share）。イベント名・日付・各セット（DJ名、開始/終了のピル、長さ）。時刻はタップでピッカー（iPhone はホイール）、開始を動かすと長さを保って終了も動く。日付またぎ対応、重なり警告、下書き自動保存
- 共有: リンクコピー / Web Share / QRコード
- 画面はタイムテーブルとタイマーの2つ。リンクを開くとタイムテーブルが出て、名前をタップするとそのDJのタイマーへ（最後に開いたDJは端末に保存され、次回は直接タイマーが開く）
- タイマー画面（スクロールしない固定レイアウト）
  - 上部にイベント名、その下に自分のDJ名（同じ大きさ）
  - 中央の上段に現在時刻（Time）と自分のセット時間（Your Set）を横並び
  - その下に Now Playing（今プレイ中のDJ名）と Next（次のDJ名）。DJ名の横に開始〜終了を小さめに表示
  - その下に出番までの時間 → 残り時間 → 超過時間を大きく表示。状態は Standby（白）→ Cue（10分前、青）→ On Air（緑 → 残り10分 黄 → 5分 橙 → 1分 赤）→ Over
  - 左上に戻るボタン（‹ = タイムテーブルへ）、右上にスリープ防止のアイコン（湯気の立つカップ = 画面を消さない / 湯気なし = オフ。使えない時は押すと理由を表示）
- タイムテーブル画面: 一覧（今プレイ中の時刻は緑）と編集・複製ボタン。名前をタップするとそのDJのタイマーへ。タイマーの ‹ や端末の「戻る」でいつでも一覧に戻れる
- 警告: 残り10分 黄 / 5分 橙 / 1分 赤点滅 / 超過 高速点滅（タップで点滅停止。Androidは振動）。動きを減らす設定では点滅せず固定表示
- 画面スリープ防止（Screen Wake Lock API）、オフライン対応（Service Worker）

## デプロイ（無料）
Cloudflare Pages / GitHub Pages に `dist/` を配置。ビルドコマンド `npm run build`、出力 `dist`。

公開URL: https://kodai-over.github.io/taite/ （`main` へのpushで GitHub Actions が自動デプロイ）
